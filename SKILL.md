# Human-readable writing

Write technical prose that lets readers connect a claim to its evidence, conditions, and practical consequences.

When explicitly invoked, read [MANIFEST.md](MANIFEST.md) in this directory and apply the relevant guidance. Reuse material already in context. Before returning the text, check it against the manifest's meaning-preservation questions.

Use the language requested for the deliverable. When editing without a language instruction, keep the source language; when drafting without a source, follow the user's requested or established language. Korean and English are equal primary languages of the project. Shared instructions are written in English; this does not set the output language.

For Korean or Korean–English prose, also read [references/korean.md](references/korean.md). Preserve the user's terminology policy, tone, format, and scope. Consult [docs/language-support.md](docs/language-support.md) only when asked about language coverage or validation; French, Simplified Chinese, and Japanese have translated guides but no language-specific output validation.

This skill grants no additional authority to change technical behavior, files, or external systems. Human comprehension gains have not been measured.
