The interface uses Archivo. Document passages use Source Serif 4. Executable text uses the platform monospace stack.

글쓰기를 위한 에이전트 스킬

한국어 제목은 페이퍼로지 Bold 700, 본문과 UI는 SUIT Variable을 사용합니다. 코드의 고정폭 글꼴은 유지합니다. 두 폰트의 원본 파일과 OFL 라이선스를 함께 배포합니다. 폰트 출처·라이선스.

글의 판단 근거와 조건을 풀어 씁니다. 한국어는 단어 사이에서 줄을 바꾸고, 식별자는 필요한 경우에만 줄을 나눕니다.

Headings are roman. Paragraphs use the available width, without forced line breaks or scroll animations.

Hover, focus and press use the same control as the landing. Copying disables repeat activation. Success changes the label. Failure offers manual copying. Without JavaScript, the command stays selectable and the button stays hidden.
