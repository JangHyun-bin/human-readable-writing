Installation and use

An installed coding agent is required. The skills CLI requires Node.js 22.20 or later. Manual installation does not require this CLI.

  1. Project installation

    The command runs from the project root and installs the skill for Codex and Claude Code. The -a options select the target agents.

    The Pi agent option is -a pi. oh-my-pi uses manual installation. OpenCode support is partial.

    npx skills add JangHyun-bin/human-readable-writing --skill human-readable-writing -a codex -a claude-code

    This installs into the current project only. Codex and Pi use .agents/skills/. Claude Code uses .claude/skills/.

    The CLI sends anonymous usage data, including this public repository and skill name. DISABLE_TELEMETRY=1 disables this reporting. Telemetry details.

  2. Invocation in a fresh session

    An invocation includes the skill name and source text. It can also specify the intended reader, language, and format.

    The skill supports English and Korean documents. It keeps the source language unless translation is requested.

    Claude Code
    /human-readable-writing
    Codex
    $human-readable-writing
    Pi / oh-my-pi
    /skill:human-readable-writing

    Example request: "The reader is a maintainer. I need a PR description that preserves the source's technical terms, facts, conditions, and uncertainty."

    OpenCode uses native skill selection. CLI invocation is not reliably verified.
