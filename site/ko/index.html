설치와 사용

코딩 에이전트가 설치된 환경에서 사용할 수 있습니다. skills CLI에는 Node.js 22.20 이상이 필요합니다. 수동 설치에는 이 CLI가 필요하지 않습니다.

  1. 사용할 프로젝트에 설치

    아래는 프로젝트 루트에서 Codex와 Claude Code에 설치하는 명령입니다. -a 옵션은 설치할 에이전트를 지정합니다.

    Pi의 에이전트 옵션은 -a pi입니다. oh-my-pi는 수동 설치로 이용할 수 있습니다. OpenCode는 현재 부분 지원입니다.

    npx skills add JangHyun-bin/human-readable-writing --skill human-readable-writing -a codex -a claude-code

    현재 프로젝트에만 설치합니다. Codex와 Pi는 .agents/skills/, Claude Code는 .claude/skills/에서 읽습니다.

    CLI는 공개 저장소와 스킬 이름을 포함한 익명 사용 정보를 전송합니다. 사용 정보 전송은 DISABLE_TELEMETRY=1로 끌 수 있습니다. 수집 정보 안내.

  2. 새 세션에서 이름으로 호출

    호출문에는 스킬 이름과 원문이 들어갑니다. 대상 독자와 원하는 언어·형식도 함께 적을 수 있습니다.

    한국어와 영어 문서에 사용할 수 있습니다. 번역을 요청하지 않으면 원문의 언어를 유지합니다.

    Claude Code
    /human-readable-writing
    Codex
    $human-readable-writing
    Pi / oh-my-pi
    /skill:human-readable-writing

    요청 예시: "독자는 유지보수자입니다. 원문의 기술 용어와 사실·조건·불확실성을 유지한 PR 설명이 필요합니다."

    OpenCode는 네이티브 스킬 선택을 사용합니다. CLI 호출의 신뢰성은 확인되지 않았습니다.
